# Advancements Together icon

The existing wordless trophy/player emblem is retained for the new name and is now also included in the mod JAR. The original generation prompt below is kept as provenance.

# Project icon

`shared-advancements.png` is the original generated artwork. `shared-advancements-256.png` is the 256×256 PNG export for Modrinth's icon size limit. The icon was made with the built-in image generation tool; the gallery uses real Minecraft screenshots, not generated gameplay images.

Generation prompt:

> Use case: logo-brand. Create a polished square icon for a Minecraft Fabric mod named Shared Advancements, for a Modrinth project thumbnail. No words or letters. Original crisp pixel-art emblem: a prominent golden advancement trophy with a small green check mark, shared by three small distinct blocky player heads below connected to it by simple pixel branches. Deep charcoal background, gold focal point, restrained cyan green and orange player accents. Bold silhouette and large simple shapes legible at 64px. Balanced centered composition, tasteful 8-bit shading, clean pixel edges, no photographic texture, no Minecraft official logo, no watermark. 1:1 square.
